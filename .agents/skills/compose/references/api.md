# Public API

For a component and the runtime setup, start with the [quickstart](../../../../docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](../../../../docs/api.md).
For typed node bindings in emitted documents, see [Design.emit](../../../../docs/api.md#designemit).
For static enum root variants, see [Design.document](../../../../docs/api.md#designdocument).
For numeric input and token components, see [Design.datatype](../../../../docs/api.md#designdatatype).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](../../../../AGENTS.md).
