# Compose contracts

For a first component, use [quickstart.md](quickstart.md). Otherwise open only the contract that your task needs:

- [api.md](api.md): public signatures, return values and failure behavior.
- [ownership.md](ownership.md): finite roots, custody, disposal, unwind and shared resources.
- [reactive.md](reactive.md): explicit dependency reads, batching and settling.
- [host-protocol.md](host-protocol.md): the host-neutral node boundary.
- [roblox.md](roblox.md): the engine adapter, viewport and input contracts.
- [scenes.md](scenes.md): existing instances, 3D scenes and tests that run with no engine.
- [design-editor.md](design-editor.md): mounting and vendoring the visual design editor, with simulated-engine coverage.
- [Build-time authoring](../authoring/README.md): content sets, semantic layouts and generated artifacts.
- [benchmarks.md](benchmarks.md): representative parity, timing and retention checks.
- [framework-comparison.md](framework-comparison.md): the latest published comparison with other Roblox UI libraries.
- [Engine verification](../verification/roblox/README.md): the engine checks and their command.

[../AGENTS.md](../AGENTS.md) defines the maintainer rules. Executable public examples are in [../examples](../examples).
Tests must refute a documented behavior.
